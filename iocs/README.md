# Indicators of Compromise (IOC) Library

## Overview

This directory contains educational reference material covering common Indicators of Compromise (IOCs) used during cybersecurity investigations.

Indicators of Compromise are pieces of evidence that may suggest a security incident has occurred. Security analysts use IOCs to identify suspicious activity, investigate alerts, and support incident response efforts.

---

## Common IOC Categories

### Network Indicators

Examples:

* IP addresses
* Domains
* URLs
* Network connections

Analysts may investigate network indicators to identify communication with suspicious or unauthorized systems.

---

### File Indicators

Examples:

* File hashes
* File names
* File locations
* File creation activity

File indicators can help determine whether a file matches known malicious activity.

---

### Host Indicators

Examples:

* Running processes
* Registry changes
* New user accounts
* Scheduled tasks

Host indicators provide insight into activity occurring on an endpoint.

---

### Email Indicators

Examples:

* Suspicious sender addresses
* Malicious links
* Unexpected attachments
* Spoofed domains

Email indicators are commonly reviewed during phishing investigations.

---

## Analyst Usage

SOC analysts use IOCs to:

* Investigate security alerts
* Search logs
* Identify affected systems
* Support threat hunting
* Improve detection rules

---

## Disclaimer

This IOC library is an educational reference created to demonstrate cybersecurity concepts. It does not represent an active threat intelligence feed.
