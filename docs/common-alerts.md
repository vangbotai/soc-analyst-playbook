# Common Security Alerts

## Failed Login Attempts

Possible causes:

* Incorrect password
* Brute-force attack
* Password spraying
* Expired credentials

---

## Privileged Account Activity

Review for:

* Unexpected administrator logins
* Privilege escalation
* Administrative actions outside normal hours

---

## Suspicious PowerShell Execution

Review:

* Encoded commands
* Remote downloads
* Script execution from temporary directories

---

## Malware Detection

Verify:

* Detection source
* Affected files
* Hash values
* Containment status

---

## New User Account Creation

Determine:

* Who created the account
* Whether authorization exists
* Assigned permissions
* Associated administrative activity

---

## USB Device Activity

Review:

* User involved
* Device identifier
* Time of insertion
* Data access following insertion
