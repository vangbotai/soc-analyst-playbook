# MITRE ATT&CK Mapping

## Overview

The MITRE ATT&CK framework is a publicly available knowledge base that documents techniques commonly used by adversaries during cyber attacks. Mapping security alerts to ATT&CK techniques helps analysts understand attacker behavior and improve detection capabilities.

## Example Techniques

| Technique            | Description                                       |
| -------------------- | ------------------------------------------------- |
| Initial Access       | Gaining entry into a target environment.          |
| Execution            | Running malicious code.                           |
| Persistence          | Maintaining long-term access.                     |
| Privilege Escalation | Obtaining higher-level permissions.               |
| Defense Evasion      | Avoiding detection by security tools.             |
| Credential Access    | Stealing usernames or passwords.                  |
| Discovery            | Gathering information about systems and networks. |
| Lateral Movement     | Moving between systems within an environment.     |
| Collection           | Gathering sensitive information.                  |
| Exfiltration         | Removing data from the environment.               |

## Why ATT&CK Matters

Using ATT&CK provides a common language for security teams, supports threat hunting, improves detection engineering, and helps prioritize defensive measures.
